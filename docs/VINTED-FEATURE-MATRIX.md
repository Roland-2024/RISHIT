# Vinted Feature Matrix

Vinted is a UX/product reference only. RISHIT will not copy its code, assets, trademarks, proprietary text, or visual identity.

| Capability | RISHIT phase/status | Adaptation principle |
| --- | --- | --- |
| Search-led header and clear sell action | Implemented | Original RISHIT design and functional catalog search |
| Server-rendered item cards with price, condition, and size | Implemented | Original component/copy; no unsupported protection claims |
| Category and brand discovery | Implemented | Database-driven bilingual labels and filterable SSR catalog |
| Listing creation and photos | Implemented | Mobile-first, honest condition, ordered validated images |
| Seller profiles/favorites | Implemented | Public seller inventory plus unique private favorites |
| Buy Now/checkout | Phase 5 | Backend totals, inventory lock, POK only after validation |
| Offers | Phase 6 | Accepted offer reuses normal checkout |
| Messaging/notifications | After commerce core | On-platform safety; realtime is enhancement |
| Shipping/order tracking | Phase 4/5 | Courier-neutral internal states |
| Buyer protection/trust copy | Phase 5/8 | Only claims supported by actual policy/provider/legal design |
| Reviews/reports/disputes | Phase 8 | Reviews tied to orders; pragmatic manual moderation first |
| Auctions | Phase 7 differentiator | Original RISHIT flow with concurrency and anti-sniping |

Public Vinted inspection on 2026-08-11 showed a compact search/navigation header, explicit sell action, dense server-readable product attributes and protection-inclusive pricing, followed by popular category/brand links. Those patterns inform hierarchy only.

Official help pages also describe feed/search/filter discovery, favorites, seller browsing, and active/hidden/sold listing management. RISHIT adapts those generic marketplace capabilities without copying Vinted text, imagery, trade dress, or unsupported payment claims.

Sources: [Vinted public marketplace](https://www.vinted.com/), [finding items](https://www.vinted.com/help/5/35-finding-items), and [listing visibility](https://www.vinted.com/help/4/60-hiding-or-deleting-a-listing).
